🚢 Matrix Battleship
A two-player physical Battleship game built with Arduino, using two 8×8 NeoPixel LED matrices and a 5-button control interface.

Overview
Matrix Battleship is a hardware implementation of the classic Battleship board game. Each player has their own 8×8 LED matrix displaying their board, and turns are taken using a shared set of directional and confirm buttons. Ships are placed, attacks are chosen, and the game ends when one player's entire fleet is sunk.
